# Collab Bot

Telegram-бот для поиска коллабораций.

## Как запустить (самый простой способ)

1. Скачайте или клонируйте этот репозиторий.

2. Создайте файл с названием `.env` и напишите в него две строки:
   ```
   BOT_TOKEN=ваш_токен_бота
   ADMIN_ID=8420676676
   ```

3. Откройте терминал в папке проекта и выполните:
   ```bash
   python bot.py
   ```

   или просто:
   ```bash
   ./start.sh
   ```

Бот запустится и начнёт отвечать на команду `/start` в Telegram.

## Что нужно заранее

- Python 3.12 или новее
- Токен бота от [@BotFather](https://t.me/BotFather)

## Структура проекта

- `bot.py` — **главный файл**, его и нужно запускать
- `src/python_project/bot.py` — весь код бота
- `collab_bot.db` — база данных с пользователями
- `.env` — ваши секретные данные (токен и админ-id)

## Если что-то не работает

- Убедитесь, что файл `.env` существует и в нём правильный токен
- Установите зависимости: `pip install -r requirements.txt`
- Проверьте, что Python версии 3.12+
